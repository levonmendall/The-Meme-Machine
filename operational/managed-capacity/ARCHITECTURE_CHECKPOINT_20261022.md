## SQLite version/ownership check

Root confirms authenticated replay receipt `39757996866`: EC2 CPython 3.12.14 / SQLite 3.45.1; local SQLite 3.53.1 is not a matched performance runtime. Official [WAL §11](https://sqlite.org/wal.html#the_wal_reset_bug) documents a rare WAL-reset race fixed in 3.51.3 / backports 3.44.6,3.50.7, requiring concurrent same-file write/checkpoint attempts from multiple connections. **No observed corruption is claimed.** This matters only as an ownership/dependency review before introducing any new checkpointer/writer. The current selector candidate changes neither; do not silently upgrade pinned runtime or attribute backlog to this issue.
