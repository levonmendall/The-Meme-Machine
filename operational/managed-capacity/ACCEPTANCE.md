cannot satisfy them. A diagnostic result grants no financial or normal PAPER
authority. The original terminal and both historical UNKNOWN handlers retain
their existing disposition.

The original host must be `i-00044d4ea1471b957`, `c6i.xlarge`, with independently
verified source, EC2/EBS identity and stopped/disabled PAPER. Require fresh
protected financial replay, zero exposure, funding closed, original source and

Use a new generation, new canonical/candidate/history/provider-usage databases,
new source identity and separate UID. Deny access to original state and full
PAPER environment. Only authenticated managed read methods are permitted.

pacing, request priorities, cooldowns, accounting and resource safeguards.
An installed profile is configuration, not proof of provider capacity.

Startup has the existing 300-second readiness boundary. The sustained window
starts only once **both** lanes have authenticated arrival and durable progress.
Acceptance requires 3,600 uninterrupted seconds within that shared window;
startup, drain, replay and restart time do not count toward it. Every failure,
restart or interval without verifiable lane coverage invalidates that window.
Allow the existing 65-second shutdown boundary; preserve unfinished work.

identical frontiers and times, including authentic skipped-slot evidence.

economic events and durable history/ACK publication. Never subtract returned
blocks from a slot span. For Pons compare canonical Robinhood blocks to

All required work finalized during the acceptance window must be durable by
the bounded final drain. Require continuous authenticated arrival samples,
complete canonical coverage without unexplained holes, no persistent growing
backlog, safe recovery after ordinary bursts, and original profile queue depth
64 / queue-wait 5-second controls. Do not redefine transport acceptance as
market arrival or candidate publication as complete canonical coverage.

consistency without lost required work, no unresolved SQLite contention or
provider reservations, and accounted provider failures/cooldowns. Verify Pons
priority-zero protection under discovery pressure with nonfunded simulations
using the original admission code and the original 3-/5-second deadlines.

latency counters, network byte counters, provider queues, coverage and backlog

existing storage headroom policy; never invent a larger allowance after a stop.
