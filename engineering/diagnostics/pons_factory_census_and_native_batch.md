# Native Pons factory replay and 64-market stage observations

This is an unselected, opt-in measurement component. It changes no strategy,
provider request, native SQLite query/transaction, funding gate or readiness
result. All exercised wire inputs are synthetic. It does not establish live
capacity, economic arrival rate, full-market processing or PAPER readiness.

`PonsEconomicCohorts.factory` observes the original `Preparation.resume()` work:
the existing database/hash verification, governed chain/genesis/provider reads,
canonical range replay, frozen-head verification and final graduation census.
The instrumentation performs no SQL, provider call or additional history scan.
It reuses the original active-candidate list. Metadata failures, contention,
overflow or an omitted hook make its own result UNKNOWN; native work and errors
retain their original behavior.

The frozen factory-domain witness binds the actual policy, provider generation,
chain/genesis, deployment digest, first/anchor, target number/hash/time and native
seven-day cutoff. It requires the complete original population range count and
contiguous source replay, the exact configured factory/topic filter, and every
native graduation's durable identity and disposition. The native reconciliation
walk must actually execute, including for an empty population. A default empty
`missing_graduations` list is not a completed census. Actual source-range coverage
is reported separately when the native candidate backlog prevents reconciliation.

An accepted structural terminal must have a non-native quote in its authenticated
factory record. An accepted horizon terminal must satisfy the original strict
age test against the frozen target. The alternative native `expired()` predicate
depends on a lifecycle `graduation_floor` that this traversal does not read;
floor-only terminal resolution therefore remains UNKNOWN here. No additional
query or inferred retention authority is used to fill that gap.

Ordinary `forward_only.ready=True` is insufficient. The inclusive seven-day
eligibility domain requires `cutoff > enrollment_at`; exact equality is still
unobserved. A retained prefix can be a recovery superset, so event counts are
retained-domain counts rather than exact seven-day economic counts. Launches can
legitimately precede the population interval and use the original candidate-specific
launch authentication. Native domain acquisition, authentication, extension and
retention invalidate the prior frozen witness before advancing their work.

The original shared `collect_v4_activities()` call accepts at most 64 native
markets. Its measurement now uses one cohort with that exact turn membership,
rather than exhausting the common eight-cohort bound after eight pools. Every
pool still traverses its original ABI/receipt decoder and its own real history
COMMIT. Side metadata admits at most 64 pending pools and 64×256 decoded rows;
each publication retains the original per-call bound. No transport, event,
candidate, source-resource or provider quota is increased. Partial/reorganized
turns remain incomplete, and the full actual market membership stays visible.

## Remaining finite composition

The frozen domain is a foundation. It does not establish current-head coverage,
all held identities, all configured Current curves, native consumer completion,
or any financial authority. The top-level pool-universe and consumer fields
remain UNKNOWN/UNESTABLISHED, and Pons never calls the Solana ACK interface.

The next native wiring must compose these witnesses, without new measurement
queries:

1. Bridge the authenticated factory head through each original complete native
   factory acquisition interval. Record original range/filter/end-hash witnesses,
   actual newly authenticated launch/graduation identities and dispositions, and
   their true cursor commits. A raw scout row count is insufficient.
2. Join every genuine graduation to the actual `MarketScout.register_pool()`
   transaction, native candidate/watch identity and policy-defined expiry. Merge
   required held identities from the authenticated original financial/native
   fence rather than assuming an empty held set.
3. Carry exact membership into each existing fair 64-market turn. Bind decoded
   rows to its original start/end/canonical hashes, per-pool prior frontier and
   real history COMMIT. Reorgs, missing members and interrupted turns remain debt.
4. Close Current work using the actual `(key,generation,desired,interpretation)`
   result, decision/audit COMMIT, qualification attempt, native pipeline outcome,
   cohort checkpoint and `Plane.consume()` COMMIT. Supersession requires genuine
   successor source coverage; an error or a terminal label cannot hide economic
   work that was never decoded/evaluated.
5. Close Survivor work using the actual graduation/pool/history checkpoint,
   canonical `pons:survivor:<token>` Plane generation, original qualification and
   attempt, durable opportunity publication and native history decision save.
   Funding denial is downstream of a genuine qualification; it cannot replace it.

These are Pons-specific consumer outcomes, not renamed source FULL/ACKs. Proper
isolated acquisition/backfill must use the existing governed native history tool
if the required authenticated pre-enrollment prefix is absent. Existing public
receipts do not currently prove either its presence or absence. A separate bounded
acquisition operation, under unchanged provider and storage controls, can supply
it; this observer cannot manufacture it from current rows.
